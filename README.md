# Vu Dinh Duc — Personal Portfolio

Hi — I'm **Vu Dinh Duc**, a third-year Computer Science student.  
This is my personal portfolio website: a simple, responsive static site that shows my projects, blog posts, gallery, and contact info.

You can find the site source (HTML, CSS, and placeholder images) in this repository.

---

## What’s in this repo
- `index.html` — Home page
- `about.html` — Short bio and skills
- `projects.html` — Selected projects
- `gallery.html` — Photos and project screenshots
- `blog.html` / `post.html` — Blog list and a sample post
- `contact.html` — Contact form and links (includes my GitHub link)
- `map.html` — Embedded map + intro video placeholder
- `HomePage.html` — small demo page
- `stylesheet.css` — Shared styling for every page
- `Images/` — placeholder images used by the pages

---

## Quick start (view on your machine)
1. Download or clone this repo.
2. Open `index.html` in your browser (double-click) **or** serve the folder with a simple HTTP server:

```bash
# from the repo root
python -m http.server 8000
# then open http://localhost:8000 in your browser
